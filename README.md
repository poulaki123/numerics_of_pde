This project solves the Laplace equation on the upper half-disk domain Ω = {(x, y) ∈ ℝ² : x² + y² < 1, y > 0}, with mixed boundary conditions — a Neumann condition on the left part of the boundary and a Dirichlet condition elsewhere. The exact solution is the function g(r, θ) = √r · sin(θ/2), which is harmonic on Ω.
The problem involves three parts. First, verifying analytically that g satisfies the Laplace equation ∆g = 0. Second, verifying that the normal derivative ∇g · n vanishes on the Neumann boundary ΓN (the negative x-axis segment). Third, solving the problem numerically and measuring how fast the numerical solution converges to the exact one.
The problem is solved using the Finite Element Method (FEM). The domain is discretized into a triangular mesh, and the solution is approximated using piecewise polynomial basis functions. The experimental convergence rate is computed by comparing the numerical error at different mesh refinement levels.

This repository implements stabilized finite element methods in NGSolve to solve the 1D advection-diffusion problem, specifically targeting the instabilities found in convection-dominated regimes. It compares the standard Galerkin method against SUPG and Galerkin Least Squares (GLS) to demonstrate how stabilization maintains high-order convergence even as $\epsilon$ approaches $10^{-12}$.
21. This repository features an implementation of a generalized Galerkin method using Nitsche’s weak boundary treatment for the advection-diffusion problem. By incorporating penalty terms and inflow boundary considerations, the scheme ensures coercivity and stability even as the diffusion coefficient $\epsilon$ approaches zero. The project provides a comprehensive convergence analysis, proving Galerkin orthogonality and comparing the method's performance against standard, SUPG, and GLS techniques. It specifically demonstrates how Nitsche-type formulations effectively suppress numerical oscillations at boundary layers in convection-dominated regimes. Finally, the included NGSolve scripts allow for easy replication of error studies across varying polynomial degrees and mesh refinements.
